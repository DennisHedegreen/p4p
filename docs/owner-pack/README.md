# Pizza4People Owner Pack

This folder holds the canonical owner-facing print collateral for the current
Pizza4People pilot lane.

The official set is now:

- `first-contact/`
  12-page A5 booklet for first handoff to a restaurant owner
- `pilot-guide/`
  8-page A5 booklet for the shop that wants to try a real first pilot
- `_legacy/`
  older flyer/fold/trifold drafts kept for continuity, but no longer canonical

## Brand Rule

For owner-facing print material, use `Pizza4People` as the clear first brand.

`P4P` may still appear as a smaller shorthand, but the outward-facing print
surface should read as `Pizza4People` first.

## Language Rule

Danish is the first canonical print language.

English may be derived later from the same master structure, but it is not part
of the first round.

## Output Rule

Each booklet must exist as:

- editable HTML/CSS master in the repo
- exported PDF in the same booklet folder
- short outline doc that explains page jobs and intended audience

The current canonical files are:

- `first-contact/first-contact-da.html`
- `first-contact/first-contact-da.pdf`
- `first-contact/OUTLINE.md`
- `pilot-guide/pilot-guide-da.html`
- `pilot-guide/pilot-guide-da.pdf`
- `pilot-guide/OUTLINE.md`

## Print Logic

The masters are built as A4 landscape booklet spreads, already imposed for:

- double-sided home or office proof printing
- center fold
- stapling/clip in the spine

Page counts:

- `First Contact`: 12 A5 pages = 6 A4 booklet pages
- `Pilot Guide`: 8 A5 pages = 4 A4 booklet pages

## Current Status

These files are part of the P4P public explanation layer, but they are not
automatically public-downloadable from `pizza4people.com` yet.

They should be tightened and reviewed as print objects first, then linked more
deliberately into the wider public lane.
