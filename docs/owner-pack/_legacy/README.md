# Legacy P4P Print Drafts

This folder holds earlier working drafts that led up to the canonical
Pizza4People owner-pack structure.

They are preserved because some language, layout, or framing may still be worth
reusing.

They are not the current source of truth.

The canonical owner-facing print system now lives in:

- `../first-contact/`
- `../pilot-guide/`

Files here should be read as:

- continuity material
- experimental draft lanes
- superseded attempts at flyer/fold/trifold structure

Do not link to these as the active owner-facing pack unless they are explicitly
revived and re-canonized.
