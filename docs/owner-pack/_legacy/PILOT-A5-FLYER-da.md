## Back

### Hvad er det?

En enkel bestillingsside til din butik.

Kunden åbner dit link, ser din menu og sender bestillingen direkte til dig.

### Hvad får du?

- dit eget menukort
- dit eget link eller QR-skilt
- direkte pickup-bestillinger
- mere kontrol over hvordan din butik ser ud online

### Hvad gør vi sammen?

1. Vi sætter din menu op.
2. Vi tester én rigtig bestilling.
3. Du får dit eget link og QR.
4. Vi følger den første pilotperiode tæt.

### Hvad er første version?

- kun pickup
- enkel drift
- ingen stor omlægning af din butik
- start småt, test roligt
