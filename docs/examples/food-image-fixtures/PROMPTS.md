# Food Image Prompt Pack

Status: prompt pack for synthetic P4P test fixtures.

Use these prompts to generate images for
`docs/examples/food-image-fixtures/`. Save outputs with the filenames listed in
[`manifest.json`](./manifest.json).

Global rules for every prompt:

- fictional test material only
- no real restaurant names
- no logos
- no branded packaging
- no QR codes
- no phone numbers
- no watermarks
- no readable real-world addresses
- no text unless the individual prompt asks for fictional UI text
